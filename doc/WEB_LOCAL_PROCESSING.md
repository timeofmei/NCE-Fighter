## 11 Web 本地处理技术与产品约束

### 11.1 范围与浏览器支持策略

只开发一个响应式 Web 应用，桌面和移动浏览器共享代码、业务和数据格式；移动端指手机或平板浏览器。静态 HTTPS 托管程序与模型，保留核心独立测试，不新增业务或远程识别服务器。

目标浏览器为较新 Chrome、Firefox、Safari，覆盖桌面、Android 和 iOS/iPadOS。老旧浏览器不做兼容回填。发布时锁定实际最低版本、OS、设备和模型组合，各项能力通过真实模型与设备测试后开放。

| 浏览器测试组 | 核心文本训练与文本导入 | PDF 与印刷 OCR | 本地整篇 ASR |
| --- | --- | --- | --- |
| 现代桌面 Chrome | 必测 | PDF、本地 GPU 和 WASM 路径 | 模型试运行和整段性能验证后启用 |
| 现代桌面 Firefox | 必测 | 不同 OS 分别检测 GPU；保留 WASM 路径 | 不按浏览器名称承诺 GPU 或速度 |
| 现代桌面 Safari | 必测 | 按实际 WebGPU/WASM 与模型算子验证 | 初始化、解码和整段基线分别验证 |
| Chrome Android | 必测 | 默认逐页、小批量，支持区域编辑 | 经设备试运行和性能门槛启用 |
| Safari iOS/iPadOS | 必测 | 逐页处理，验证触控、存储与图像限制 | 经设备测试，额外验证锁屏和后台中断 |
| Firefox Android | 必测核心功能 | WASM 路径优先实测，GPU 仅按能力启用 | 未验证时禁用并说明原因 |

检测流程不能只判断 navigator.gpu 或 WebAssembly 是否存在。状态区分 unavailable、needs_download、initializing、ready、failed，必要时增加 degraded；实际获取适配器、加载所选模型、检查语言和算子、预热和基准测试后才认为识别能力可用。某功能失败不阻断已可用的键盘训练。

### 11.2 本地候选依赖与版本冻结

以下为接入阶段候选方案，不要求将模型或库依赖放进统一核心。

| 功能 | 候选方案 | 接入门槛 |
| --- | --- | --- |
| PDF 文字提取与页面渲染 | pdfjs-dist 即 PDF.js | 阅读顺序、逐页处理、Worker 与异常恢复 |
| 印刷体图片文字行识别 | PP-OCRv6_tiny_rec 与 onnxruntime-web | ONNX 文件、预处理、解码、词表、语言覆盖及浏览器试运行 |
| 可选 OCR 模型 | PP-OCRv6_small_rec | 对应语言支持和准确率实测后，由用户按需选择 |
| 整篇录音批量转写 | @huggingface/transformers 与 Whisper Tiny | 英语候选 Tiny.en，非英语候选多语言 Tiny；显式传入支持的语言 |
| 可选原生本地识别 | 支持 processLocally 的原生 SpeechRecognition | 必须确认为本地并支持所选语言，不改变整篇流程 |
| 数据保存与资源缓存 | IndexedDB；模型资源采用 Cache Storage，必要时 OPFS | 学习数据与模型缓存分离、迁移和清理测试 |

先评估满足要求的浏览器原生本地能力，缺少合适能力时使用库和模型。录音结束后的批量转写默认用本地 Whisper 路线；原生语音接口不是必需项，普通 SpeechRecognition 不能被当成保证本地的兜底。选用原生实现时需 processLocally=true、语言包检查和失败处理，不能将此值关闭后继续转写。

PaddleOCR.js 高层管线不能直接视作 rec-only SDK。接入时核对锁定版本是否要求 det 与 rec；若要求检测模型则不选该高层管线，直接用 ONNX Runtime 加载识别模型并实现其前后处理。模型是否可直接取得 ONNX、导出是否正确、解码头及词表是否配套，都在接入验收中核查；通用 CTC 解码不能未经检查用于所有导出。

锁定清单需包含依赖版本、模型版本、实际模型文件、语言清单、精度配置、输入输出、许可证、字节数和缓存校验标识。模型标称覆盖语言数不代替本产品的逐语言验收；语言模块支持与模型覆盖分别注册。两条 ONNX 依赖链检查打包和 WASM 资源重复情况，不能未经兼容验证强行共用运行时。

PP-OCRv6 当前模型介绍将 tiny 标为 49 种语言且不含日语，small 包含日语；因此日语不能沿用 tiny 默认项，需选择已验证的 small 或其他本地模型。具体名单按锁定模型与词表核对；一个多语言识别权重可供多个独立语言文本模块共用，两者不要求一对一配置。

### 11.3 PDF 与图片 OCR 流程

文字版 PDF：浏览器读取文件 → PDF.js 逐页 getTextContent → 使用文字坐标和行信息恢复阅读顺序 → 文本块与页号 → 所选语言模块整理 → 用户校对。避免仅用 join 拼接造成分栏和段落错序；PDF 自带语言元数据不替代用户选择。

扫描页：PDF.js 逐页渲染 → 区域预处理与行裁切 → 本地 rec 模型 → 按用户确认顺序拼接 → 校对。混合 PDF 按页优先取可信文字层；低质量文字层允许用户手动改为 OCR。初始扫描分辨率候选约 150 至 200 DPI，依据实际页面大小与模型限制调整，不将固定 DPI 等同于固定像素占用。

图片：本地解码 → 方向与尺寸处理 → 已有坐标、用户框选或非神经网络分行 → 文本行识别。已知语言不能推导文字位置；采用 rec-only，不下载或运行神经文字检测 det 模型。可选二值化、水平投影或连通域分行，但无可靠区域时提供人工框选，不保证任意多栏、倾斜或复杂版面能全自动处理。

来源图片、识别区域、页号和顺序保留关联；旋转或缩放后坐标需能映射回来源。失败可逐页或逐区域重试，成功内容保持；失败文本不自动补全。优先单页执行、复用模型会话和词表，及时释放 Canvas、ImageBitmap、张量和结果缓存。

手写全文采用图片输入、识别校对和全文比对流程，模型需有该语言手写测试集和真实照片验证。tiny 或 small 的语言覆盖、下载大小及印刷体结果不能证明手写质量；不足时另选本地识别模型或暂时禁用该语言手写入口，不调用云端模型替代。

### 11.4 录音与 ASR 流程

Web 录音使用可用的麦克风、录制和 Web Audio 本地接口；录制格式通过运行时检测选择，记录 MIME 类型。准备完成后由用户点击开始；结束后保留音频引用、可回放记录和原始转写。

音频处理：Blob → 浏览器本地解码 → 单声道 16 kHz 样本 → 内部任务批次 → 约 30 秒窗口与少量重叠 → 本地 Whisper 推理 → 重叠去重与按顺序拼接 → 用户确认完整文本 → 一次全文比对。窗口跨句不改变用户训练单位，不产生多个背诵成绩。

英语候选 Whisper Tiny.en；非英语使用已验收的多语言模型并显式设置语言参数，不自动检测或误用 .en。约 30 秒窗口和重叠参数为调试起点，需锁定版本验证；边界合并须避免重复或吞掉单词。无语言支持、初始化失败或浏览器不能解码时说明原因，可保留音频并重试，不静默换语言、上传或截断。

上传音频文件作为可选 Web 输入扩展，进入同一整篇转写确认流程，不作为核心引擎首版阻塞条件。不保证任意音频编码；文件解码不支持时提示可用格式，必要解码器也按需本地加载。

### 11.5 GPU 与 WASM 调度

WebGPU 是优先评估的后端，WASM 是本地回退。实际步骤：请求 GPU 适配器 → 建立该模型会话 → 预热和基准测试 → 选择满足兼容、内存和耗时的后端。GPU 初始化或算子失败时释放会话后创建 WASM 会话；不能只改配置却继续复用已失败会话。

对小型 OCR 同时考察初始化、数据传输和推理总耗时；WASM 若更快或更稳定可以优先。WASM SIMD 和多线程是否启用分别检测；线程需要的共享内存与跨源隔离由静态托管配置验证，不具备时仍尝试可用单线程路径。

推理和重型预处理尽量放进 Worker；DOM、权限与需主线程的能力留在宿主。Worker 内后端不可用时采用经验证的其他本地运行路径，不承诺全部浏览器都能在 Worker 跑同一模型。移动端默认 OCR 单页、ASR 单任务，队列、图片像素、Canvas 和音频解码峰值内存都有限制；不能只根据压缩文件大小判断能否处理。

设备测试缓存记录模型、后端、精度、运行时、浏览器及测试日期，模型或环境升级后重新验证。性能过慢或内存不足只禁用对应识别能力，保留课文、草稿和键盘训练。

### 11.6 下载 缓存与本地数据

首屏不加载 OCR、ASR 模型和不需要的 PDF 代码。首次使用对应功能时才加载资源。下载开始前显示用途、已知资源量和语言；单功能不同时拉取多个精度或大小的模型。所有模型与配置从本站批准路径加载，禁止运行时临时访问第三方模型仓库。

| 候选资源 | 规划量级 | 实际验收口径 |
| --- | --- | --- |
| PDF.js 基础资源 | 规划估算约 1 至 2 MB | 测量实际构建，另计字体、CMap 和其他资源 |
| PP-OCRv6_tiny_rec | 官方模型存储量级约 4.4 MB | ONNX 实际文件大小及全部配套资源另测 |
| PP-OCRv6_small_rec | 官方模型存储量级约 20.4 MB | 可选下载，不将其作为所有语言的默认模型 |
| OCR 运行时与词表 | 规划估算额外数 MB 至十余 MB | 按锁定构建测量，不只展示权重大小 |
| Whisper Tiny.en | 规划估算量化组合约 41 MB、FP16 约 76 MB | 精确以选定 encoder、decoder、tokenizer 和配置清单统计 |
| ASR 与共享运行时 | 额外资源量依版本而变 | 检查重复依赖并统计冷加载总下载量 |

估算只用于规划，不显示为已经保证的流量。冷启动下载、初始化、预热与热处理耗时分开记录。下载失败可重试，缓存校验失败不启用损坏模型；必要时重新下载并提示。

课文、版本、训练和草稿建议存入 IndexedDB；模型缓存与学习数据隔离。来源文件、图片和音频是否长期保存由清楚的用户选项控制，不能把 Blob URL 当作跨刷新持久引用。处理失败时至少保留当前页面可用输入；刷新恢复只有写入持久存储成功才承诺。

缓存可被浏览器回收，存储请求拒绝、配额不足或隐私模式需清楚提示并保留导出入口。模型清理不删除学习记录，学习数据导出不必包含大模型权重。P08 允许查看资源、重测设备、清理模型以及导出记录；不增加模型市场或训练功能。

本地推理与完全离线分别验收。首次下载可联网；若发布离线能力，需缓存应用壳及对应模型、配置、词表、WASM、Worker 和必要 PDF 资源，断网重载后验证实际功能。PWA 安装不是本版前置条件，不把部分模型缓存成功当成整个应用已离线。

### 11.7 性能与设备门槛

采用[验收标准第 8 节](DELIVERY_PLAN.md#8-验收标准)的核心比较性能目标，识别性能另行测量。以下为待验证的热处理目标，不是实测结果；固定语言、样本、像素量、模型精度、后端、设备和版本。英文基线不自动适用其他语言或手写。

| 任务基线 | 桌面目标 | 移动目标 |
| --- | --- | --- |
| 已准备区域的普通英文 OCR | 不超过 5 秒 | 不超过 10 秒 |
| 一页文字版 PDF | 约 1 秒 | 不超过 2 秒 |
| 一页扫描 PDF 含区域预处理和 OCR | 不超过 5 秒 | 不超过 10 秒 |
| 完整 180 秒英文音频 | 不超过 60 秒 | 不超过 90 秒，实测达标才启用 |

音频实时倍率 R=T处理/T音频，180 秒基线上桌面目标约 R≤0.33，移动目标 R≤0.5。记录整条热处理流程及纯推理时间，不把只测一个短窗口当成完整录音结果；同时测试峰值内存、发热与中断。模型初始化时间另记，但功能开放需同时满足稳定性和可接受的完整等待体验。

像素缓冲区下限 M=W×H×4 字节，2000×3000 的 RGBA 缓冲约为 24 MB，实际加上复制、模型张量和渲染更高。逐页和限并发属于内存门槛，不等于禁止用户导入多篇 PDF。正式文件大小、页数、像素、队列与录音上限在发布前给出，超限在处理前提示，不静默丢页。

### 11.8 本地处理与静态部署

站点通过 HTTPS 提供程序、模型和运行时。按选用功能配置 CSP、Worker 路径及必要的 COOP/COEP；相关资源从本站加载并验证缓存、跨源规则和版本一致性。跨源隔离不能满足时降级单线程本地路径，不建设识别代理绕过限制。

用户课文、图片、PDF、音频及识别文本不离开浏览器，不写入远程统计、日志或错误上报。网络验收覆盖下载请求参数、请求体、遥测及错误信息，单靠 UI 文案或 CSP 不能替代检查。模型和语言包可下载，但不能把用户内容作为下载参数。

### 11.9 Web 接入验收

B 类属于 M5 至 M7，核心 C 与 A 类验收不依赖真实模型。

| 编号 | 场景 | 必须得到的结果 |
| --- | --- | --- |
| B01 | 发布到现代桌面与移动浏览器 | 支持表列明实际最低版本、OS、测试设备和功能状态 |
| B02 | 首次访问后仅做键盘训练 | 不下载 OCR、ASR 或不需要的 PDF 资源 |
| B03 | 多语言、不同输入能力 | 语言传递明确，仅启用相应已验证能力 |
| B04 | GPU 不可用、模型算子失败或 GPU 更慢 | 可用时重新建立 WASM 路径，不调用远程识别 |
| B05 | GPU 和 WASM 均失败或性能不达标 | 禁用相应识别并说明原因，键盘训练可继续 |
| B06 | 多文件、文字层与扫描混合 PDF | 按页选择提取或 OCR，保留来源、顺序和成功结果 |
| B07 | rec-only 图片与扫描 PDF | 不下载运行 det；区域失败可人工框选和调顺序 |
| B08 | 手写照片输入 | 按语言独立验收，未经验证不标为已支持 |
| B09 | 完整录音超过三分钟 | 不拆成多个用户作答；支持范围内内部拼接后统一检查，未支持时事先说明 |
| B10 | ASR 窗口与批次边界 | 不重复或丢失边界内容，不逐窗口评分 |
| B11 | 本地原生 SpeechRecognition 可用或失败 | 只采用明确本地模式，失败不改为远程识别 |
| B12 | 模型下载中断、缓存损坏与版本升级 | 明确状态，重试、校验或重测，不使用损坏资源 |
| B13 | 清理模型缓存 | 学习数据保留，可重新下载；不混同删除课文 |
| B14 | 本地存储配额不足或被回收 | 明确保存失败或资源需重下，提供数据导出，不保证跨设备同步 |
| B15 | 手机键盘、横竖屏、触控与输入法 | 输入和操作可见，切换不丢草稿，合成中不误提交 |
| B16 | 拍照、录音权限拒绝与后台中断 | 文件选择或键盘替代可用，中断按 R04 处理 |
| B17 | 多页扫描与完整 180 秒音频压力测试 | 记录峰值内存、稳定性与总耗时，落实页数和并发限制 |
| B18 | 识别全流程的网络请求检查 | 文件、音频、正文与结果不发送远程服务或日志 |
| B19 | 声明离线支持后的断网重载 | 应用与所需资源可用，否则只声明本地推理 |
| B20 | 锁定资源清单和静态部署 | 依赖、模型、词表、精度、资源量和缓存标识可追溯，安全上下文与 Worker 配置通过 |
