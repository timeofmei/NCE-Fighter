# NCE Fighter 页面与交互设计

版本：0.4　日期：2026 年 10 月 11 日

本文涵盖 P01 至 P08、页面跳转和通用交互。训练规则见[产品需求](PRODUCT_REQUIREMENTS.md)，识别能力与资源约束见[Web 本地处理](WEB_LOCAL_PROCESSING.md)。返回[项目文档导航](../README.md#项目文档)。

## 1 核心页面设计

这些页面统一作为响应式 Web 交互规格，按阶段交付可运行入口；正式跨浏览器与设备能力在发布阶段验收。涉及[待审核产品默认值](PRODUCT_REQUIREMENTS.md#5-待审核默认值与待验证参数)的布局和示例同样待审核，不能据此提前实现后续阶段。

界面日期时间统一按浏览器时区显示为 `YYYY-MM-DD HH:mm`，使用 24 小时制，不显示秒；适用于训练记录、最近训练时间、结果完成时间及删除确认窗口。

全局页头中“NCE Fighter”与 logo 位于同一行，名称靠左、logo 靠右；点击名称返回课文库，点击 logo 在新标签页打开 [GitHub 仓库](https://github.com/timeofmei/NCE-Fighter)。

### P01 课文库

目标：找到已确认课文，并继续导入或训练。

导出用户数据期间显示居中的“正在导出”窗口，阻止鼠标、触摸和键盘操作其他页面内容，不允许通过遮罩、Escape 或关闭按钮提前解除。文件生成并触发下载后自动关闭；失败时解除阻挡，显示错误并允许重试。不承诺浏览器下载到磁盘已经完成。

JSON 文件选择并校验通过后，显示居中的确认对话框，标题为“导入用户数据”，正文为“将合并现有数据，是否确认导入？”，底部提供“取消”“导入”。不预览课文内容，不逐条处理冲突。取消不修改数据；确认后执行原子导入，成功关闭弹窗并刷新列表，失败在弹窗内显示错误并允许重试。

“课文库”标题行右侧并排提供“导入/导出”和“帮助”按钮。“导入/导出”点击打开居中的对话框，提供“导入”和“导出”两个操作；导入选择用户数据 JSON 并按既定规则恢复，导出将全部已保存用户内容写入一个 JSON，不再选择语言或导出范围。此全库操作不在阅读或训练页重复放置；加号卡片继续用于新增原始课文。“帮助”点击打开居中的对话框，不显示标题和关闭按钮，中间显示帮助内容，底部提供“确定”按钮。

由上到下：全局页头；课文库标题；搜索标题；语言及“已确认／待校对”筛选；课文卡片列表。列表第一项始终为与课文卡片相同样式的导入卡片，不参与课文排序和筛选，中间仅显示加号，不显示文字，整卡点击进入导入；保留“导入课文”的无障碍名称。课文卡片显示标题、语言、句数和状态；点击整张已确认卡片进入详情，点击待校对卡片进入编辑。卡片内不放操作按钮。训练接入后显示最近训练时间。同一课文库可同时保存不同语言课文。

待校对卡片长按 650 毫秒打开删除草稿确认框，按住期间背景色逐渐变为浅红；提前松开、移出、指针取消或移动超过 10 CSS px 时取消长按，滑动不打开编辑。完成长按后的松手不再触发卡片跳转。键盘聚焦卡片后 Enter 打开，Delete 或 Backspace 打开草稿删除确认。已确认卡片只提供打开行为，暂不接入长按删除。

已保存草稿的编辑页仍提供“删除草稿”按钮，与卡片长按复用同一 Modal：左上角显示课文标题，未填写时显示“未命名课文”；正文说明删除后无法恢复的后果，编辑页有未保存修改时说明将一并放弃。取消返回原状态，失败在弹窗内显示错误并允许重试；成功后课文库更新，编辑页返回课文库。

无课文时列表只显示加号导入卡片；筛选无匹配时也保留导入卡片。加载失败保留重试入口。原始材料导入先选择语言，输入方式按所选语言的可用能力显示；JSON 导入沿用文件内各对象的语言。

### P02 导入

目标：将原始材料校对为可信标准答案，或从 JSON 恢复用户内容及原状态。

原始材料导入必填“语言”，列表来自可用语言模块，不含“自动检测”。选择后才启用已接入的输入方式。粘贴文本一次一篇；文件提取或识别流程中的多个文件共用一个批次语言选择，不为每篇重复设置；不同主语言的材料分批导入。用户主动改选时，就近说明重新分析的实际影响；处理中的旧任务失效。JSON 导入不要求统一选择语言，不进入重新校对流程；恢复后草稿仍可编辑，已确认课文仍只读。

正文采用多行编辑窗口，每个非空行代表一句；编辑器关闭自动换行，长句在输入框内横向滚动，只有实际换行才开始下一行；错误按编辑器原行号定位，不另设行号预览区域。桌面可并列展示来源与编辑窗口，移动端单列或切换来源视图。底部提供“保存草稿”和“保存为课文”，用一处状态显示未保存修改或草稿保存成功。确认窗口左上角显示当前课文标题，未填写时显示“未命名课文”；内容仅保留确认后的只读约束与本地数据保存风险提示、“继续编辑”“确认保存”按钮和关闭按钮。标题字段标签为“标题”，独立编辑，正文为主要区域。

粘贴文本直接进入单篇逐行编辑器，不展示多篇列表、分篇或合并操作。文件提取或识别接入后提供处理进度、来源预览、待确认课文列表及课文边界拆分和合并。编辑窗口提示“每行一句”。粘贴文本保留用户换行；图片或 PDF 按整批可用内容统一分篇、自动分句后填入正文。编辑后保留用户行边界。失败部分重试成功或用户明确跳过后才进入校对，不能把尚未完成的项目显示为全部完成。

Web 接入后增加识别区域编辑：旋转图片、选择文字区、确认行顺序、拆分或合并行。仅识别 rec 模型接收裁好的文本行或其支持的区域；整页自动分行失败时回到手动框选，不能凭空猜测文字。桌面可拖拽框选，移动端提供缩放、可触达的控制点和单区域调整。文件读取、资源下载、模型初始化、逐页识别分别显示进度与取消。

#### 文件批次交互

本节定义 PDF／OCR 的文件批次交互，实际验证与用户验收状态见[阶段 04](stages/04-document-ocr.md)。

- 入口沿用 P01 的加号卡片。P02 在选择语言后提供“粘贴文本”和“文件导入”；JSON 继续使用课文库的用户数据操作窗口。PDF 每次只能选择一个文件；图片可以多选，按顺序作为连续材料处理，再统一提出一篇或多篇课文。
- 桌面左侧为待校对课文列表，右侧为当前选中课文的标题、正文编辑区及来源查看；窄屏在列表、当前编辑和来源视图之间切换，保持主要正文编辑空间。
- 每篇提供“保存草稿”和“保存为课文”，不提供批量保存为课文。确认完成后从待校对列表移除该项，其他项保持可处理。
- 选择另一篇、切换输入方式或离开有未保存修改的编辑项时，提供保存草稿后继续、放弃修改后继续和取消切换。刷新或关闭使用浏览器允许的原生离开提醒，不承诺拦截浏览器关闭或系统终止。
- 拆分放在当前草稿编辑区，在用户选择的正文行边界拆成两篇；合并放在课文列表，只能选择同一批次、同语言的草稿，并确认正文顺序，不提供跨批次合并。拆合用于修正自动分篇，仅处理草稿；已保存草稿一次完整保存全部结果，涉及未保存修改先处理保存／放弃／取消。事务契约见[核心引擎](CORE_ENGINE.md#29-文件批次与草稿拆合契约)。
- 来源预览中的旋转、框选和阅读顺序只影响所选页面或区域，控件放在来源编辑区内。重新识别执行前确认将丢弃当前未保存草稿及校对修改；已保存草稿留在队列最前面，新结果排在后面，不覆盖已保存内容。
- 识别期间显示阻止页面内导航与输入方式切换的进度对话框，保留“取消识别”。取消后停止任务，丢弃本轮未保存结果，保留已保存草稿，关闭对话框并返回导入页。刷新、关闭网页或地址栏跳转导致任务中断时，同样不恢复未完成结果。
- 页面或图片识别失败时，在进度对话框内提供重试失败部分、跳过失败部分并继续、取消识别。重试保留本轮成功内容，只处理失败部分；跳过时提示正文可能缺失。失败已解决或明确跳过后，按整批可用内容统一分篇，再关闭对话框进入校对。

已保存正文和来源定位可恢复；原始 PDF／图片不长期保存，刷新后预览或重新识别须重新选择并核对原文件，见[产品需求 I08／I09](PRODUCT_REQUIREMENTS.md#41-导入与课文校对)。

#### 模型选择与下载

选择文件并点击“开始识别”后，才按实际任务准备所需资源。文字版 PDF 可直接提取时不下载 OCR 模型；图片、扫描页或混合 PDF 的 OCR 页面需要模型时，检查所选模型缓存，缺少资源则显示下载确认对话框。打开页面、选择语言或粘贴文本不触发模型下载。

对话框按用户之前选择的内容语言和当前印刷／手写任务，列出已验证支持该语言及任务的模型；技术候选不直接成为正式可选项。显示模型名称、本次需下载的资源总量，以及帮助选择的实测速度／准确率差别。默认选择该语言与任务的推荐模型；只有一个适用模型时直接显示该模型，不增加选择控件。

点击“下载并识别”后进入资源下载、初始化和识别进度；取消下载确认保留所选文件。相同语言和任务优先沿用上次选择且仍适用的模型，资源已缓存时不重复下载确认。模型切换控件归属于文件导入的识别操作区；切换至未缓存模型时仍须确认下载。所选模型不再适用时重新选择，不静默改选语言。

资源管理页负责查看下载状态、失败重试、设备重测和缓存清理，见 [P08](#p08-本地资源与设备能力)。资源量依据锁定清单和现有缓存计算，不能用官方模型存储大小代替实际首次下载总量。

### P03 课文详情与训练入口

目标：阅读课文并决定如何训练。

顶部显示标题，标题行右侧提供复制图标按钮，点击复制完整正文，保留换行与空白，不包含标题和行号；不使用悬浮提示。复制成功后，按钮下方短暂弹出“已复制全部课文”，按钮显示勾选图标；失败时在同一位置提示重试。中部显示正文，行号可点击或用键盘激活，选中对应行的全部课文文字，不包含行号；正文仍可直接选择。提供“返回课文库”操作。正文下方并排提供“逐句默写”“全文默写”两个训练入口，窄屏空间不足时自动换行。逐句入口直接开始无提示训练，提示切换在训练页提供；全文的“保存草稿”只放在全文训练页。真实录音接入后再提供“整篇背诵”，手写接入后在全文训练页提供输入方式选择。底部显示最近记录；课文保持只读。版本绑定保留在数据中，页面不展示内部版本 ID 或导入校验单位统计。

待确认课文只显示“继续编辑”。按当前语言提供已接入的提示、OCR 和 ASR 操作；已接入功能因设备或权限等运行条件不可用时，说明与用户操作有关的具体原因。不提供面向用户的模拟背诵入口或页面。

每条训练记录置于独立的圆角矩形边框内，按训练类型、完成状态、时间的顺序显示，使用户可以直接识别该条记录属于哪种训练。训练类型和完成状态使用有背景色的标签，类型名称与对应训练入口一致；真实录音记录显示“整篇背诵”。不同类型使用不同颜色；“逐句默写”为蓝色，“全文默写”的类型标签背景为紫色 RGB(102, 8, 116)，即 #660874，文字使用白色；全文记录复用当前列表、读取与删除操作。“已完成”为青绿色，“未完成”为橙色，时间使用次要文本。记录旁提供“查看结果”或“继续训练”，以及“删除记录”。删除确认窗口以课文标题及该条记录时间标识对象，说明输入、作答和结果删除后无法恢复；存在关联重练时说明重练记录保留。失败在弹窗内显示错误并允许重试，成功后更新记录列表及最近训练时间。删除范围按产品需求 S08，课文不受影响。

### P04 逐句默写

目标：一次记住并检查一个句子。

顶栏：返回、课文标题、进度 2/8、提示模式。主区：提示模式才显示当前语言模块返回的提示片段；多行输入框；“提交本句”。不重复展示当前句序号与进度。输入框占据页面主体，键盘弹出后提交按钮仍可触达。使用语言对应的内容方向；提示不要求是首字母行。桌面可提供 Ctrl 或 Cmd 加 Enter 提交，普通 Enter 保留换行；输入法合成中不提交。默认进入无提示模式，显式提交后才展示结果。

未提交输入不自动保存，不显示保存状态；刷新或离开直接丢弃，不弹出未保存确认。打字期间输入框持续可编辑，保留焦点；提交后才保存本次作答。

提交后在输入框下展开：本句结果 → 你的输入 → 标准原句 → 差异说明；底部提供“下一句”，仅在本句存在差异或跳过时显示“重写本句”，完全正确时隐藏。错误名称与数量按比较单位显示，例如英语词遗漏、其他模块的字或单位遗漏。进入下一句时折叠本句答案。末句主按钮改为“查看本次结果”。

页面示例：输入 I had a good seat.；提交后显示“遗漏 1 个词：very”，标准原句 I had a very good seat.。进入下一句前不自动跳转，让用户能看清反馈。

### P05 全文默写

目标：独立完成全文，中途没有答案反馈。

键盘输入页顶部显示课文标题和“全文默写”，保留返回操作。主体为较大的多行输入框，字号与导入正文一致，按内容方向渲染；下方并排提供“保存草稿”和“提交全文”，窄屏空间不足时换行。保存草稿成功或失败时就近短暂反馈，不常驻保存状态，也不自动保存。提交前不显示标准原文、提示或实时差异；点击“提交全文”直接比较并进入结果页，不增加确认弹窗。输入法组词尚未完成时不触发快捷键提交。

手写接入后才提供键盘／手写输入方式选择；手写方式显示图片队列与顺序调整，能力按当前语言启用，底部操作为“识别手写内容”。

手写识别完成后进入确认视图：图片与识别文本并排，窄屏上下排列；“返回图片”“确认文本并检查”。识别失败保留照片，上传顺序影响最终拼接顺序。提交前不显示标准原文。

移动浏览器提供拍照或从相册选择入口，浏览器不支持相机入口时保留普通文件选择。需要下载本地手写模型时，先说明资源量、语言和用途；下载失败保留照片，允许重试或改用键盘，不切换远程识别。

### P06 整篇背诵

目标：连续背诵整篇，并把识别错误和记忆错误区分开。

准备状态：标题、开始按钮，申请麦克风权限前就近说明录音用途。仅呈现已接入的 ASR 操作；语言直接传给 ASR，用户不需要重新选择。录音状态：醒目的录音指示、计时、必要的输入音量反馈、“结束背诵”“取消”；没有逐句按钮和匹配进度。

结束后：转写处理中 → 识别文本确认页 → 结果页。确认页可回放录音、编辑转写文本，并显示“请仅修正识别错误”；主按钮“确认文本并检查”。客户端可选择是否持久保存音频，需有清楚控制；核心只保存音频引用，不保存设备对象。

Web 录音需在用户操作后申请权限，正式站点使用 HTTPS。录音开始前完成必要模型准备和设备检查；录音结束后才显示本地批量转写。移动端切后台、锁屏或资源回收不保证录音连续，须显示中断状态并按 R04 恢复，不显示虚假的“仍在录音”。超过三分钟不会自动拆成多个用户作答。

### P07 统一训练结果

目标：看懂错在哪里，并决定下一次怎么练。

顶部显示课文标题、训练模式，以及影响结果解读的提示使用或识别文本修改状态；查看历史记录时显示完成时间。版本与比较配置保留在数据中。摘要显示模块对应的准确度名称、遗漏、多余、替换及单位名称。主体按原文句序排列，默认突出错误项，可展开正确句；每句展示原文与作答，并用文字标签说明差异。不把不同语言、模块或比较粒度的准确度混合排名。

逐句训练的正确反馈统一显示“完全正确”，摘要显示首次完全正确、错误、跳过和重试情况，统计规则见产品需求 S06。逐句结果提供“重练错误与跳过句”“重新练习整篇”“返回课文”；错句重练创建新的逐句会话，并保留原始句序标识。整篇背诵不显示发音分。

全文默写结果顶部显示课文标题、“全文默写”和完成时间；摘要显示“完全正确”或“存在差异”、模块对应的准确度、遗漏、多余及替换数量。先完整展示“你的输入”和“标准课文”，保留实际换行，按比较单位标绿、标红；英语按词标色。下方按原句顺序列出具体差异，完全正确的句子默认收起。全文不显示逐句首次正确统计。底部提供“重新默写全文”和“返回课文”，不提供错句重练；重新默写创建新会话，保留原记录。逐句与全文复用差异标色及历史查看组件。

### P08 本地资源与设备能力

此页属于 Web 接入阶段，不是核心引擎 MVP 的必交页面。可从课文库设置和功能不可用说明进入。显示本地语言能力、可用 PDF/OCR/手写/ASR 功能、检测结果、待下载或已缓存模型、预计及实际资源量、初始化状态和重试入口。用户操作为“下载所需资源”“重新检测”“清理模型缓存”“导出学习数据”。

显示下载、初始化与实际处理为不同阶段；同一功能不默认下载多种精度模型。清理模型不删除课文和训练记录；清理学习数据须明确区分。已接入功能因设备、权限或资源失败而不可用时，保留恢复入口与具体原因，不只依据浏览器名称隐藏用户原本能使用的训练。尚未接入的功能不呈现占位入口或开发进度提示。

### 1.2 通用交互规则

所有对话弹窗在视口中水平、垂直居中，包括保存确认、删除确认和离开确认。

界面简洁与文案要求统一遵循 [AGENTS.md](../AGENTS.md#应用界面与文案)。本文件仅维护页面操作与用户反馈；输入要求、不可逆后果和数据风险在相关操作处呈现，尚未接入的功能不展示占位说明。

普通 UI 文本不允许选中；输入框、可编辑文本、课文句子和详情页课文标题保留文本选择与复制能力。其他位置的标题、句序号及操作标签按普通 UI 文本处理。

核心作答页突出一个主要动作。输入保存按各模式规则处理：逐句不保存未提交输入，全文键盘提供手动保存草稿；不以通用规则自动增加保存或离开确认。提交后的原文与作答按模块比较单位标色：匹配单位标绿，替换单位在两侧标红，多余单位在作答中标红，遗漏单位在原文中标红；保留原有空白与标点。错误反馈不能仅靠红绿颜色，必须保留遗漏、替换、多余文字标签。输入框、按钮和状态提示支持键盘操作与清楚标签。页面骨架与业务动作跨语言复用，内容方向、提示片段、单位标签和语言特有错误说明由模块元数据控制；输入法合成期间不触发提交或破坏光标。

响应式布局建议以约 900 CSS px 作为宽窄布局切换起点，并按实际组件宽度调整。桌面校对可并列，移动端使用单列和步骤切换；虚拟键盘弹出后输入区和主要操作可见，底部操作避开安全区，不依赖 hover。触控目标建议至少约 44×44 CSS px；正文可放大，主要操作不能产生横向溢出。横竖屏切换保留输入；裁图可在独立视图缩放。桌面快捷键是补充，移动端始终有可点击操作。

课文文本、文件名和模型输出都作为普通文本展示，不能执行其中的脚本或富文本指令。Web 本地路线不提供 API Key 或远程识别配置；识别与访问统计的网络边界见[本地处理与静态部署](WEB_LOCAL_PROCESSING.md#18-本地处理与静态部署)，页面不增加云端兜底。
