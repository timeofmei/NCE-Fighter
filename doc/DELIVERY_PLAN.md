## 8 验收标准

| 编号 | 场景 | 必须得到的结果 |
| --- | --- | --- |
| A01 | 已选英语，Lesson 1 和 Lesson 2 文本一起导入 | 得到两个有序英语草稿，可修正边界 |
| A02 | 一篇跨页、单页多篇的提取文本 | 不依据页数强制分篇，可人工合并和拆分 |
| A03 | 图片或 PDF 提取、识别正文包含 Mr. Smith 与小数 | 自动分句不机械切分每个句点，用户可逐行校对 |
| A04 | 草稿未确认或正文仅标点 | 无法开始训练，指出原因 |
| A05 | 各模块的大小写与标点忽略用例 | 无内容单位差异时正确；空白按所选语言规则处理 |
| A06 | 英语 Hello,world 与 hello world | 完全正确 |
| A07 | 英语 Don't 与 dont；Don't 与 do not | 前者正确，后者有词差异 |
| A08 | 缺 very、多 good、had 写成 have | 分别输出遗漏、多余、替换 |
| A09 | 各语言全文漏掉中间一句 | 后续正确单位仍能对齐，缺句标遗漏 |
| A10 | 多余单位导致错误率大于 1 | 保留原始计数，准确度最低为 0 |
| A11 | 无提示作答页面尚未提交 | 不展示原句、任何提示或比较单位数量 |
| A12 | 开提示后关闭再提交 | hintUsed 仍为 true |
| A13 | 跳过或看答案后重写正确 | 不计入首次独立通过 |
| A14 | 全文输入尚未提交 | 没有实时答案反馈或准确度 |
| A15 | 录完整篇但尚未确认转写 | 不显示最终训练结果，无按句暂停功能 |
| A16 | OCR 或 ASR 失败后重试 | 保留输入，不产生已完成记录 |
| A17 | 保存后尝试编辑课文或训练时升级模块 | 课文只读；已有会话的标准答案和规则不变 |
| A18 | 相同语言、模块、配置、文本重复比较 | 结果与对齐位置一致，包括重复内容用例 |
| A19 | 导出后重新载入 | 课文版本、句子顺序、作答与规则版本可还原 |
| A20 | 提交双击、取消任务后旧结果返回 | 不重复保存，旧任务不覆盖新状态 |
| A21 | 空输入、超长输入或边界无效 | 明确返回校验错误，不崩溃或静默截断 |
| A22 | 无浏览器、无网络、无真实模型 | C01 至 C12 仍能通过固定输入完成验收 |
| A23 | 未选择内容语言就上传、粘贴或导入 JSON | 阻止导入，不启动识别或语言分析 |
| A24 | 选择语言后开始识别 | languageId 全程传递，不自动检测或改选 |
| A25 | 未安装模块，或只有其他语言的 ASR 可用 | 不自动回退英语；按当前语言禁用缺失能力 |
| A26 | 添加一个采用不同单位和提示规则的模块 | 通过同一接口复用三种训练、存储和结果页面 |
| A27 | 草稿改语言或 JSON 语言与选择冲突 | 显式处理并重新分析；旧任务结果不能覆盖新语言 |
| A28 | 已确认课文尝试改语言或加载升级模块 | 阻止改语言；历史规则保持，旧版本缺失时明确阻止继续 |
| A29 | 非词单位与词单位训练结果 | 正确显示单位及指标，不把非词单位标成 WER |
| A30 | 附加符号、字素簇、文字方向与输入法用例 | 不将文字信息作为标点删除；范围有效，按方向显示，合成中不误提交 |
| A31 | 任一自定义对齐返回结果 | 计数按单位，结果契约、原文映射与句子归属有效 |
| A32 | 中文界面导入其他语言，或导入缺失语言字段的数据 | 界面与内容语言独立；缺失语言字段明确报错，不自动补入英语 |

性能验收建议先固定一个测试基线：参考与输入各不超过 1,000 个比较单位的单篇课文，比较耗时 p95 小于 200 ms，使用固定设备和运行环境分别记录每个语言模块的分析与对齐耗时。此目标为待实测指标，不是已有性能；字单位和词单位的容量不能视为同样长的文本。文件大小、PDF 页数、录音时长限制由适配层明确公布；核心支持按模块配置的单位数上限，不静默截断。

## 9 开发里程碑

**M1 统一契约与课文结构。** 确定语言模块接口、注册机制、语言选择前置、数据格式、正文范围映射和草稿确认流程。退出条件：语言必填、导入、校对、确认、序列化和版本绑定用例通过。

**M2 共享比较工具与语言模块。** 实现单位序列对齐、确定性回溯、错误统计与句子聚合；开发者分别实现首批语言的归一化、比较单位、提示和必要的自定义对齐；图片与 PDF 正文的自动分句在 M5 接入。退出条件：各模块契约测试通过，遗漏整句、重复内容、空文本、超限与语言特有用例通过；开始采集性能。

**M3 统一训练状态。** 实现逐句两种提示、全文提交、整篇背诵文本确认、首次结果与复练记录。所有语言共用状态机。退出条件：同一套状态与事件测试对首批模块通过，不依赖真实 OCR 或 ASR。

**M4 最小演示与交付。** 通过文本、JSON 和固定识别结果验证完整闭环，交付统一引擎、首批语言模块、接口说明、分语言示例和测试报告。退出条件：C01 至 C12 及核心 A 类验收通过；A03 的图片与 PDF 自动分句在 M5 验收，性能结果及限制明确。为证明多语言解耦，建议至少用两个比较单位或提示规则不同的模块验收；具体首批语言由开发者决定，测试模块不标为正式语言支持。

**M5 Web 文档与 OCR 接入。** 在核心里程碑完成后依次接入 PDF.js、本地文字行 OCR、区域编辑和扫描 PDF 逐页处理，接入提取、识别正文的自动分句；增加 Worker、模型按需下载、缓存、语言能力检测与响应式校对。手写输入按语言单独验证，未经验证不标为已支持。

**M6 Web 整篇背诵接入。** 接入浏览器录音、音频解码与重采样、Whisper 本地转写、整篇合并和用户确认；用完整 180 秒基线及更长整篇测试验证性能和中断恢复，按设备启用 ASR。

**M7 Web 发布验收。** 锁定现代浏览器支持表、依赖与模型版本，完成桌面和移动浏览器的 B 类验收，发布静态站点和本站模型资源。离线支持如发布则独立验收；不开发原生移动端。新增语言模块与新增浏览器本地识别模型可以独立推进。

## 交付阶段与里程碑对应

阶段按可运行用户流程划分，M1 至 M7 保留为工程里程碑；阶段完成不自动代表整项里程碑通过。详细安排和实际验收记录只维护在对应阶段文档。

| 阶段 | 范围 | 对应里程碑 | 状态 |
| --- | --- | --- | --- |
| 01 | 文本导入、逐行校对、确认只读及本地恢复 | M1 的基础子集，提前提供最小 Web 验证入口 | 待审核：[阶段文档](stages/01-text-import.md) |
| 02 | 比较与逐句训练 | M2、M3 的逐句部分 | 未开始 |
| 03 | 全文训练、文本模拟背诵、JSON 与核心交付补齐 | M1 剩余项、M3 剩余项、M4 | 未开始 |
| 04 | PDF、OCR 与资源管理 | M5 | 未开始 |
| 05 | 录音、本地 ASR 与恢复 | M6 | 未开始 |
| 06 | 浏览器和设备验证、静态发布 | M7 | 未开始 |

多篇边界建议、完整语言模块能力与多语言契约验证仍属于核心交付要求，须在 M4 前完成。后续阶段细节在准备该阶段时审核，不将本表视为已确认的全部实现设计。
