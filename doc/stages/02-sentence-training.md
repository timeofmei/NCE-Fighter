# 第二阶段：比较与逐句训练

## 状态与范围

状态：开发中（已审核并获实现授权，代码尚未开始）。用户已于 2026 年 10 月 11 日确认文档并授权实现。

目标：已确认的英语课文可逐句默写，提交后查看词差异，完成后查看首次结果与复练记录；输入、进度和结果的恢复按已审核契约实施。

覆盖 [M2 与 M3 的逐句部分](../DELIVERY_PLAN.md#2-开发里程碑)：交付 C05、C06 的英语逐句能力，以及 C08、C12 所需的存储与共享契约部分。完整多语言验证、全文训练与核心交付补齐继续按整体计划推进，不将本阶段验收写成全部核心验收通过。

本阶段不接入全文默写、背诵、JSON、PDF、OCR、ASR 或已确认课文删除。删除策略仍按产品需求 I06 另行确定；应用不呈现这些功能的占位入口。

按以下顺序推进；常规工程细节在现有授权范围内自主处理，涉及产品行为或重要契约变更时按协作规则审核。

| 顺序 | 工作 | 验证重点 |

| 1 | 核查第一阶段遗留问题，确定本阶段模块与数据库结构；补齐上述契约 | 新数据可保存与恢复，课文快照及会话规则绑定正确 |
| 2 | 扩展语言接口，实现英语 prepare、提示与共享对齐工具 | 英语规则示例、遗漏／多余／替换、重复词、Unicode 范围和确定性 |
| 3 | 实现平台无关的逐句状态与统计 | 提示粘性、答案查看、跳过、重写、首次分类及错句重练 |
| 4 | 扩展 IndexedDB 训练存储及恢复 | 原子提交、请求去重、写入失败、刷新和旧任务失效 |
| 5 | 接入详情训练入口、逐句页面、结果页与历史结果读取 | 提交前答案隐藏、反馈与导航、键盘／触控和输入法 |
| 6 | 完成自动验证、生产构建和可运行交付 | 记录实际命令与结果，提供用户验收版本 |

沿用现有工程分层，不增加业务后端或全局状态库。核心状态通过宿主注入 ID 和时间，语言模块不依赖 UI 或存储；页面组合 Mantine 控件，不复制比较与统计规则。

详情本阶段只接入逐句训练和相应记录。输入为可编辑文本；标准答案仅在提交或跳过后显示，切换句子与重写时按 S01、S05 隐藏。差异使用原文范围及文字标签展示，不依赖颜色判断。页面不额外解释已经由控件、布局表达清楚的操作。

### 自动验证计划

- 单元测试：英语规范用例、码点映射、固定回溯、计数与准确度；会话事件、四类首次结果、重试与完成条件。至少使用一种不同单位或提示结构的测试模块验证逐句共享契约，不标为正式语言支持。
- 集成测试：事务失败与重试、重复 requestId、自动保存顺序、恢复 checked／answering／completed、缺失版本和损坏记录；确认快照不可变。
- 浏览器测试：入口到结果与重练闭环、刷新恢复、提交双击、存储失败保留输入、快捷键与输入法；回归导入、草稿删除、卡片交互和第一阶段离开警告。
- 静态检查与生产构建：按工程指南执行 typecheck、lint、单元／集成测试及 build。浏览器验证区分生产预览与开发故障入口，确保测试配置使用的服务地址与端口正确。
- 性能：固定设备和运行环境，分别记录英语分析与对齐耗时、样本规模及 p95；据此报告容量限制，不预先宣称目标达成。

本阶段主要验证 A04–A08、A10–A13、A17–A18、A20–A21 的相关场景，以及 A25、A28–A32 的逐句契约部分。A09 可用核心对齐固定输入验证漏句，全文页面验收留待后续。各编号的全部语言或全部模式要求不在本阶段一次完成。

## 用户验收

执行条件：已审核范围实现，自动验证与生产构建完成。交付时补充实际版本及访问地址；同一浏览器、同一站点来源测试恢复。当前所有步骤均未执行。

准备一篇英语课文并确认保存，正文每行一句：

```text
I had a very good seat.
Don't stop.
Hello,world!
```

| 项目 | 操作 | 可观察结果 |
| --- | --- | --- |
| 入口与隐藏 | 从详情开始无提示逐句训练，输入但不提交 | 显示进度与输入区，不展示原句、提示、词数或实时比较结果；草稿不能训练 |
| 正确与差异 | 分别测试大小写／标点变化；首句漏 very、多一个 good、had 改 have；第二句输入 dont stop 和 do not stop | 正确用例与核心英语规则一致；错误明确区分遗漏、多余、替换并定位原文 |
| 提示记录 | 新会话第一句开提示、关闭，再正确提交 | 提示内容符合审核后的英语规则，关闭后仍计为提示使用；不计为独立正确 |
| 重写与跳过 | 首句错误后重写正确；第二句跳过；继续完成 | 重写清空输入并隐藏答案；原始错误与跳过保留，复练正确不覆盖首次结果 |
| 结果与重练 | 查看汇总，重练错误与跳过句，再返回历史结果 | 首次分类覆盖本次句子，重试另计；重练保持原句序，历史结果不变 |
| 恢复 | 分别在输入保存后、提交后、下一句及完成后刷新；返回详情继续或查看记录 | 恢复已保存输入、提示与答案查看状态、进度和结果，不重复提交或泄露下一句答案 |
| 操作与回归 | 用按钮及 Ctrl／Cmd+Enter 提交，输入法合成中测试快捷键；窄屏输入；继续导入、编辑、删除草稿 | 合成中不误提交；主要操作可触达；第一阶段功能保持可用 |

存储失败、版本缺失与损坏数据由自动测试注入验证，用户无需操作数据库。真实移动端输入与触控体验在交付时单独记录，不以桌面模拟结果替代。
