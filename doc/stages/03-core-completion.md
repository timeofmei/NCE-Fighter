# 第三阶段：全文训练与核心交付补齐

## 状态与范围

状态：文档审核项已确认，已授权实现，代码尚未开始。用户于 2026 年 10 月 12 日授权实现本阶段已确认范围；本次安排为完成文档提交，暂不开始代码实现。自动验证和应用验收均未开始。

目标：在已完成的英语逐句训练基础上，交付全文键盘默写及 JSON 导入导出，通过测试适配器验证背诵核心流程，补齐统一核心引擎的可运行闭环与契约验证。

本阶段对应 [M1 剩余项、M3 剩余项与 M4](../DELIVERY_PLAN.md#2-开发里程碑)，同时检查 M2 的完整正文对齐及多语言契约依赖。交付本阶段适用的核心范围；C02／A02 的多篇提议与拆合、A03 的图片／PDF 自动分句在后续文档识别阶段验收，不作为本阶段已经交付的能力。

正式支持语言沿用已验收的英语。采用另一种比较单位和提示结构的测试模块验证共享流程，不将测试模块加入正式支持列表；若要新增正式语言，先审核该语言规则和验收范围。

本阶段不接入真实 PDF、OCR、手写识别、麦克风录音、ASR、模型资源管理、账户或云同步。识别相关核心流程通过固定文本与可控失败的测试适配器验证，不将模拟结果当成真实识别能力。已确认课文删除策略仍待另行确定。

## 实施安排

| 顺序 | 工作 | 验证重点 |
| --- | --- | --- |
| 1 | 按已确认范围整理模式状态和接口 | 遵循已确认 JSON 字段与事务规则，引用有效，未确认行为不进入实现 |
| 2 | 验证单篇文本导入与训练扩展兼容 | 一次粘贴一篇，保留用户行边界，不引入自动分篇或多篇拆合 |
| 3 | 扩展共享会话、识别确认和完整正文比较 | 模式差异由数据表达，漏句后续仍正确对齐，不复制训练业务 |
| 4 | 实现多模式存储、统一用户数据导出和原子恢复 | 草稿／课文状态保留，单句／全文范围校验分清，UUID 覆盖合并、本机独有记录保留、失败回滚和旧写入失效 |
| 5 | 接入全文页及统一记录／结果 | 提交前隐藏答案，历史只读、类型标签明确、删除及重练可用 |
| 6 | 验证核心输入适配器与不同规则测试模块 | OCR／ASR 固定输入、失败、取消、旧任务返回；三种训练均可复用 |
| 7 | 完成必要回归、容量与性能验证及用户交付 | 逐项记录 C／A 覆盖、实际结果与未验证边界 |

粘贴文本保持一次一篇，按用户换行确定句子；课号、标题或空行不触发自动分篇。多篇提议与草稿拆合仅在后续文件提取或识别阶段处理，本阶段不实现相关界面。

全文键盘直接比较整篇输入；背诵的原始转写、确认文本、修改标记及结果关系通过测试适配器验证，不建立模拟背诵用户页面。固定手写识别文本通过测试适配器验证相同确认契约，不在页面提供不可用的照片入口。

共享结果组件继续使用原文范围标色；完整正文的参考范围属于课文，输入范围属于整篇作答，不能用输入换行或相同句序号替代完整序列对齐。全文只支持重新默写全文，逐句结果继续保留错句重练；两者均创建新会话。

### 自动验证计划

- 核心测试：三种模式的提交／确认、跳过与重练契约；整句遗漏、开头／结尾多余、重复句、跨句对齐、Unicode 映射及单位计数；至少一种不同单位或提示结构的测试模块复用全部模式。
- 导入测试：粘贴含多个课号或标题的文本仍只形成一篇草稿，保留行边界；空句与超限、未选语言阻止原始材料分析；JSON 保留各对象语言与状态，不重新校对。
- 存储与序列化测试：全部已保存用户内容的 JSON 往返，包括多种语言、课文草稿、全文输入草稿、三种模式历史与来源依赖；同 UUID 完整覆盖、旧文件覆盖较新进度、草稿／课文跨状态覆盖、本机独有记录保留、重复导入不增加记录、事务回滚、旧写入失效、未知版本、损坏范围和缺失模块；历史结果不能重算。
- 适配器测试：固定 OCR／ASR 文本、确认修正与未修改标记、失败重试、取消后旧结果返回、内容语言全程传递；无模型、无网络、无 DOM 的核心测试可运行。
- 浏览器测试：全文输入到结果、错句重练、多模式记录查看／删除、导入导出恢复；回归逐句、导入草稿、复制正文和行号选句，验证窄屏及输入法合成。
- 工程验证：按工程指南执行类型检查、lint、单元／集成测试、关键浏览器流程和生产构建。性能使用既定样本方法测量分析与对齐，验证大量记录的导入导出及实际处理失败的回滚，不设置用户数据总量或 JSON 容量拒绝阈值，不将目标写成已通过。

核心验收逐项映射 A01–A32：C02／A02 的多篇提议与拆合、A03 留待文档提取与识别；涉及录音、OCR／ASR 的 A15／A16／A24 在本阶段仅验证固定输入适配器及共享状态，真实设备、权限和识别质量仍留待对应 Web 阶段。本阶段适用的功能或契约缺口必须关闭，不能用逐句已经通过替代全文验证及背诵核心契约测试。

| JSON 状态恢复 | 导入同时包含草稿、已确认课文和训练记录的文件，另测试缺失语言与无效关联 | 不要求重新选择语言或校对；草稿可继续编辑，已确认课文保持只读；无效数据明确报错，I09、A23／A27／A32 |
| 全文隐藏与正确反馈 | 进入全文模式，输入大小写和标点变化的全文，提交 | 提交前无原文或实时差异，提交后显示“完全正确”，F01、A05／A14 |
| 全文差异 | 漏第二句，或在句间增加内容，保留后面的 Hello,world! | 遗漏／多余清晰，后续正确内容仍对齐，A09、核心第 1.3 节 |
| 全文结果与重练 | 查看完整标色及逐句差异，再重新默写全文 | 正确句默认收起，无错句重练按钮；重新默写创建新记录，原记录保留，F04、P07 |
| 草稿与恢复 | 全文输入后保存草稿，再修改但不保存并刷新；另测试提交完成后恢复 | 全文恢复最后一次成功保存的草稿；已提交结果可恢复，不重复生成作答 |
| JSON 往返与合并 | 将全部已保存用户内容导出为一个文件，在空数据范围恢复；修改同 UUID 记录后重新导入，另保留本机独有记录 | 草稿、已确认状态、语言、句序、模式、已保存输入、作答与版本绑定还原；同 UUID 以文件为准，新增记录导入，本机独有记录保留，重复导入不增加记录，A19、I09 |
| 记录与删除 | 查看逐句与全文模式记录，取消删除，再删除一条来源记录 | 类型可辨，取消保留；删除不影响课文，关联重练保留，S08 |
| 输入与回归 | 窄屏输入全文、合成中使用提交快捷键；继续逐句与草稿校对 | 不误提交，主要输入与操作可用，已验收流程不退化 |

事务故障、缺失模块、非法 JSON、固定识别失败和取消等由自动测试验证，用户不需要手工修改数据库。真实录音、手写照片、跨浏览器与离线能力不在此表中宣称验收。
