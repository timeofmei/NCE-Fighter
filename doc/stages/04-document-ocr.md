# 第四阶段：PDF、OCR 与资源管理

## 状态与范围

状态：产品与交互文档审核完成，实现已授权。2026 年 10 月 12 日开始文档准备、完成逐项审核并取得按审核范围实施的授权；代码实现未开始。技术可行性、自动验证和用户应用验收均未执行。

目标：在第三阶段已验收的课文与训练流程上，接入浏览器本地文件处理，使用户能从单个 PDF 或连续多张图片生成待校对课文，完成分篇、分句、校对与确认，并管理所需的本地识别资源。本阶段对应 [M5](../DELIVERY_PLAN.md#2-开发里程碑)，阶段编号与工程里程碑编号分别使用。

已审核范围：文字版 PDF 提取、图片与扫描 PDF 的印刷体 OCR、混合 PDF 逐页选择处理方式、来源区域编辑、多篇草稿提议与拆合、英语自动分句、逐项进度／取消／失败恢复，以及适用的资源下载、缓存和设备能力管理。输入入口及校对交互引用 P01／P02，资源管理引用 P08。

正式语言限定为英语，以该语言完成真实材料与模型验证。新增正式语言需要独立审核语言规则、模型覆盖和验收样本；测试模块不能自动成为正式语言。英语手写单独验证，质量及设备门槛达标后才开放图片导入和全文默写手写输入；不达标时另行审核后续安排，不能以印刷体 OCR 或固定结果代替手写验收。

麦克风录音与 ASR 按第五阶段推进；账户与云同步不属于本次范围。全面浏览器支持表、静态发布及完整离线能力按第六阶段验收，但本阶段必须验证实际运行所需的 Worker、本站资源路径和本地数据边界。未经验证的识别能力不能通过正式入口提供。

## 实施安排

本表按审核结论安排，已获授权执行；常规代码组织、队列实现和组件复用由开发者处理。授权包含材料准备、候选技术验证及本阶段已审核功能实现，新增正式语言或未达标手写能力的后续安排仍须独立审核。

| 顺序 | 工作 | 验证重点 |
| --- | --- | --- |
| 1 | 依已审核范围准备真实材料与可重复的试运行样本 | 所属规范一致，材料可使用且不含敏感个人内容，测试设备和参考正文明确 |
| 2 | 验证并锁定 PDF、OCR 运行时及模型资源 | 实际文件、前后处理、解码与词表配套、许可证、本站资源路径、下载字节数及缓存校验标识 |
| 3 | 扩展文件批次、来源和多篇草稿契约 | 来源顺序、语言传递、草稿拆合、保存事务、JSON 版本和完整恢复；旧任务不写回新状态 |
| 4 | 接入文字版 PDF 逐页提取与预览 | 阅读顺序、分栏、跨页、多篇、空页及无效文件；不以页面作为课文边界 |
| 5 | 接入图片与扫描 PDF 的来源区域编辑和印刷体 OCR | 旋转及坐标映射、裁行、识别顺序、手动框选、逐页／区域重试、释放图像与模型资源 |
| 6 | 实现语言模块的文件分篇建议与自动分句 | 标题与课号提议、缩写／小数、保留原文及来源；进入编辑后使用用户最终行边界 |
| 7 | 接入多篇校对、逐篇保存与确认 | 单个正文框控制当前课文、未保存修改处理、同批拆合、确认只读、重新识别保留已保存草稿 |
| 8 | 接入按语言与任务选择模型、下载确认、资源管理及实际可用后端 | 文字提取不加载 OCR；过滤已验证模型、真实下载总量、缓存复用、下载取消与重试、设备检测及 GPU／WASM 实际失败恢复 |
| 9 | 按审核结论验证手写范围，并完成回归及交付 | 手写独立验证；既有文本、训练和 JSON 流程不退化，实际限制和未验证边界明确 |

### 自动验证计划

- 核心与模块：无真实模型的文本块来源顺序、跨页课文、单页多篇、草稿拆合、句子与来源映射、英语缩写／小数自动分句，以及粘贴文本不调用文件分篇或自动分句；覆盖 C02／C03、A01–A03、A21–A24、A27／A30／A31。
- 存储：依定稿契约验证批次、来源和草稿保存／恢复、拆合中途失败回滚、确认与删除的依赖、迟到写入拒绝、新格式 JSON 往返和非法关联拒绝。原文件缺失或未持久化时不得假装预览或识别可以恢复。
- 文件适配器：真实文字 PDF、扫描 PDF、混合 PDF、图片旋转与裁切；损坏、加密或不支持的文件明确失败，取消后旧结果丢弃，部分成功保留，来源定位可追溯。
- OCR：固定结果用于共享状态与异常测试，真实模型另验证语言、预处理、解码、识别质量、GPU／WASM 路径及失败恢复；不得把模拟适配器测试当作 B06／B07 的真实验收。
- 资源：首次键盘流程不加载 PDF／OCR／ASR，实际使用时按需加载；下载中断、错误响应、损坏缓存、版本更换、初始化失败与设备重测；清理模型不删除学习数据。
- 浏览器：从加号卡片进入文件导入，单个 PDF／连续多图分篇、当前编辑项切换、来源预览、拆合、逐篇保存确认及刷新；回归粘贴、逐句／全文训练、JSON、窄屏、触控与输入法合成。
- 性能与网络：分别记录下载、初始化、预热、PDF 提取、区域处理与推理耗时；测试多页扫描的峰值内存、取消和释放；检查文件、正文及识别结果不进入远程请求或统计。性能目标引用本地处理规范，不提前写为通过。
- 工程：按工程指南执行类型检查、lint、单元／集成测试、关键浏览器流程和生产构建。真实模型及设备结果须标明运行环境、模型文件与版本，不能仅以浏览器特性存在判为可用。

本阶段重点完成 B02–B07、B12–B15、B17（多页扫描部分）、B18／B20 的适用验证；B08 按手写审核结果处理。B01 的完整发布支持表、B09–B11 的 ASR、B16 的录音权限与中断、B17 的完整音频压力测试、B19 的离线重载分别留待对应阶段。图片文件选择及可能接入的相机能力仍需验证实际可用性。

## 用户验收

状态：未执行。以下为已审核范围对应的验收计划，实际访问方式、测试设备、资源清单与材料文件将在实现交付时补齐。

先使用桌面 Chromium 环境完成主要流程和处理上限实测；窄屏模拟用于布局检查，触控及识别稳定性仍需真机验证。手机暂用保守临时上限，真机验证保持待办，不以桌面或模拟结果认定手机识别已通过。模型下载首次需要网络；用户材料只在浏览器本地处理，不能把这一点等同于已支持断网重载。

准备材料：有可核对参考正文的英语文字版 PDF；Lesson 1 跨页、同页含 Lesson 2 的材料；扫描与文字层混合 PDF；含缩写、人名首字母和小数的正文；清晰印刷图片、旋转图片及需要手动框选的版面；一个损坏或不支持的文件。真实英语手写照片单独准备并验证。材料由开发者从可合法使用的公开来源准备，记录许可、参考正文及必要的派生方式，不要求用户提供。

| 项目 | 操作 | 预期可观察结果及依据 |
| --- | --- | --- |
| 入口与语言 | 从课文库加号进入，选择语言后选择 PDF／图片 | 文件在导入页处理，JSON 入口保持其原有用途；未选语言不开始分析，A23、P01／P02 |
| 文字 PDF | 选择文字版材料，检查提取正文及来源 | 原文可核对，文字和阅读顺序正确，标题与课号不混入标准正文，I01–I04、B06 |
| 多篇与跨页 | 选择跨页及同页多篇材料，检查分篇建议并调整 | 不按页数划分课文，可在草稿阶段拆分／合并，A01／A02 |
| 文件批次 | 检查 PDF 单选，选择连续多张英语图片 | 图片按顺序作为连续材料统一分篇；正文框只编辑当前篇，人工合并仅限同批次，I02、P02 |
| 自动分句与校对 | 检查缩写、小数等边界，再人工修改行边界 | 初始句子可校对，确认使用最终非空行，不再次自动拆句，A03、I03／I04 |
| 来源区域 | 旋转图片、框选文字区域并调整阅读顺序 | 处理范围与所选区域一致，来源预览可定位；自动分行失败可人工调整，B07 |
| 印刷 OCR | 识别清晰图片及扫描页，校对后保存为课文 | 使用真实本地 OCR，确认前可修正；保存后课文只读并可进入已有训练，B06／B07、I06 |
| 部分失败与取消 | 在进度对话框重试失败页／图片、明确跳过或取消 | 页面内导航被阻止，成功识别内容保留；失败解决或明确跳过后统一分篇，跳过提示缺失；取消丢弃本轮未保存结果，A20、B06 |
| 重新识别与中断 | 保存一篇草稿，修改另一篇后重新识别；再测试网页关闭 | 重新识别先确认丢弃未保存草稿，已保存项在前、新结果在后；关闭网页不恢复未完成结果，P02 |
| 多篇编辑与保存 | 编辑一篇后切换另一篇，测试保存、放弃、取消及刷新 | 未保存修改按保存／放弃／取消处理；显式保存的正文可恢复，来源预览须重选并核对原文件，I08 |
| 模型选择、下载与清理 | 点击开始识别，检查按已选语言及任务列出的模型；测试下载确认、取消、失败重试、缓存复用和清理 | 文字提取无需 OCR；只提供已验证适用模型，实际下载量可判断，取消保留文件；缓存后不重复下载确认，清理不删除学习数据，B02／B03、B12–B14 |
| 窄屏与回归 | 在移动视口查看来源与编辑课文，再进行逐句／全文训练和 JSON 恢复 | 当前任务主要操作可用，输入法合成不误触发确认，既有功能保持可用，B15 |

事务故障、缓存损坏、后端失败及网络数据边界由自动验证和开发者设备测试覆盖，用户无需手工修改数据库或模型。完成本表不代表所有浏览器、任意版面、手写或离线能力已验收。
