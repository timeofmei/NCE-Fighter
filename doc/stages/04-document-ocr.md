# 第四阶段：PDF、OCR 与资源管理

## 状态与范围

状态：2026 年 10 月 12 日已按审核范围实现，并通过自动验证；用户应用验收与手机真机验证待执行。本阶段对应 [M5](../DELIVERY_PLAN.md#2-开发里程碑)。

实现范围：英语文字版 PDF、扫描 PDF、混合 PDF、连续图片的浏览器本地印刷体 OCR；来源预览、旋转、手动框选、区域拆合与阅读顺序；整批多篇提议、自动分句、逐篇校对保存确认及同批草稿原子拆合；进度、取消、部分失败重试与明确跳过；模型下载确认、缓存校验、设备重测和独立清理。既有文本导入、逐句／全文训练和 JSON 流程保持可用。

正式语言为英语。真实历史手写样本独立验证未达标，图片导入和全文默写不开放手写识别；后续模型或手写安排须另行审核。录音与 ASR 留待第五阶段；完整浏览器支持表、静态发布及断网重载留待第六阶段。

## 自动验证与性能记录

2026 年 10 月 12 日验证环境：Windows 11 Pro 10.0.26300，Intel Core i7-12700H，约 32 GB RAM，Playwright Chromium 156.0.8078.4。模型为官方 PP-OCRv6_tiny_rec ONNX、FP32、onnxruntime-web 1.30.0、Worker 单线程 WASM；冻结版本、许可和完整资源大小见[技术规范](../WEB_LOCAL_PROCESSING.md#12-本地候选依赖与版本冻结)及[校验清单](../../app/adapters/ocr-manifest.json)。requestAdapter 实测返回 null，未开放 GPU，也不声称 GPU 模型算子已验证。

| 检查              | 实际结果                                                                 |
| ----------------- | ------------------------------------------------------------------------ |
| npm run typecheck | 通过                                                                     |
| npm run lint      | 通过                                                                     |
| npm test          | 8 个文件、90 项单元／集成测试通过                                        |
| npm run build     | 静态生产构建通过，PDF／OCR Worker 与本站辅助资源输出成功                 |
| npm run test:e2e  | 36 项通过，含 11 项真实文件／真实 OCR 流程及既有训练、JSON、开发故障回归 |
| npm audit         | 0 个已知漏洞                                                             |

新增核心及存储验证涵盖跨页／多篇、缩写／小数、来源映射、原子拆合回滚、操作重放、迟到写入、删除依赖及 JSON 往返／非法关联。浏览器验证涵盖文字／扫描／混合文件、图片顺序、手动框选、旋转、失败页重试跳过、下载中断取消、损坏缓存重下、重测清理、窄屏、刷新后原文件指纹核对及逐篇确认。测试使用真实识别权重，不用固定文本代替 OCR。

公开材料与参考正文见[样本说明](../../tests/fixtures/documents/README.md)及 [reference.json](../../tests/fixtures/documents/reference.json)：Joseph Jacobs 1894 年《伊索寓言》的公版正文生成可重复的文字／扫描／混合 PDF；另包含原始数字化印刷封面和 1864 年 Lincoln 手稿扫描。合成扫描样本与原始历史扫描分别标注，未使用用户私人文件。

| 材料                        | 读取／准备 | 热处理总耗时 | 纯推理      | 质量结果                                  |
| --------------------------- | ---------- | ------------ | ----------- | ----------------------------------------- |
| text.pdf，2 页              | 258.6 ms   | 不需 OCR     | 0           | 提取正文、跨页及同页多篇与参考一致        |
| scan.pdf，2 页，1200×900    | 170.0 ms   | 516.7 ms     | 453.1 ms    | 正文与参考逐行一致                        |
| stress.pdf，50 页，1200×900 | 262.5 ms   | 12,691.9 ms  | 11,406.4 ms | 逐页完成，无中断；每页约 0.17–0.39 秒     |
| 原始印刷封面人工裁行        | 26.8 ms    | 26.3 ms      | 15.3 ms     | “Fables”正确；复杂封面需人工区域          |
| 原始手稿首行人工裁行        | 18.5 ms    | 25.3 ms      | 15.9 ms     | 参考“Washington”，输出“MaMvajion”，未达标 |

各次会话初始化约 196–249 ms，预热约 30–34 ms，独立于表中的热处理时间。OCR 完整冷下载清单为 18,818,017 字节；网络速度未作为性能结论。上述为单设备单次材料测量，不代表任意版面或手机性能。

测量脚本为 [measure-document-runtime.mjs](../../scripts/measure-document-runtime.mjs)。Windows 通过进程树工作集采样得到本轮浏览器峰值约 741.4 MiB，包含浏览器、渲染器及 Worker；采样间隔包含 CIM 查询时间及额外 500 ms，不能视为精确分配峰值。扫描样本单页 RGBA 缓冲为 4,320,000 字节；逐页复用模型，完成／取消释放 Worker、图像和页面资源。限制的唯一规则见[性能与设备门槛](../WEB_LOCAL_PROCESSING.md#17-性能与设备门槛)。

本站资源 URL 固定，下载校验大小及 SHA-256，取消保留已校验缓存；损坏缓存不用于初始化。PDF／图片、正文和识别结果在本地处理；键盘入口不请求 PDF／OCR 资源。完整线上统计及发布网络边界仍按第六阶段验收，当前结果不等同于完全离线能力。

## 用户验收

状态：未执行。启动 `npm run dev`，访问命令输出的地址；或先 `npm run build`，再 `npm run preview`。首次 OCR 下载需要网络，后续同站点使用校验缓存；不同端口属于不同浏览器存储来源。

材料全部位于 [tests/fixtures/documents](../../tests/fixtures/documents/README.md)。桌面先执行以下操作；窄屏模拟只用于布局，手机触控、内存、速度及后台中断仍需真机验证。

| 操作                                                          | 预期结果                                                           |
| ------------------------------------------------------------- | ------------------------------------------------------------------ |
| 课文库加号 → 英语 → PDF／图片，选 text.pdf                    | 提取两篇建议，第一篇跨页；正文不混入标题，来源可预览               |
| 编辑缩写、小数及句子换行，逐篇保存并确认                      | 采用最终非空行；已确认课文只读并可进行原有训练                     |
| 选 page-1.png、page-2.png 或 mixed.pdf                        | 按连续材料统一分篇；图片／扫描页运行本地 OCR，文字页不运行 OCR     |
| 选 rotated.png 或 printed-cover.jpg，旋转、框选并调整区域顺序 | 识别所选范围；封面“Fables”可人工裁行，复杂版面不保证自动恢复       |
| 保存草稿，拆分／合并并刷新                                    | 仅同批同语言可合并，保存结果完整恢复，不留下被合并旧草稿           |
| 切换编辑项、返回或重新识别                                    | 未保存修改按保存／放弃／取消处理；重新识别保留已保存草稿           |
| 保存后刷新，重新选择原材料及错误材料                          | 正文保持；原文件核对通过恢复预览，错误文件拒绝匹配                 |
| 添加 blank.png、broken.pdf，重试、跳过或取消                  | 失败清楚反馈；成功页保持，明确跳过后统一分篇，取消不写入未保存结果 |
| /resources 下载、重测、清理，再导出／恢复 JSON                | 初始化及预热实际执行；缓存清理保留学习数据，版本 2 保存来源定位    |
| 窄屏编辑、来源调整、逐句／全文训练与输入法操作                | 当前任务操作可用，切换不丢已保存草稿，输入法合成不误确认           |
