# 阶段 01：文本导入与只读课文

## 状态与范围

状态：待用户验收。用户于 2026 年 10 月 11 日确认方案并明确授权本阶段代码实现、自动验证和可运行交付，随后确认提交全部实现及调整；实现已完成，用户应用验收尚未执行。

目标：交付可以运行的文本导入闭环，覆盖课文库、语言选择、粘贴文本、逐行校对、草稿保存与删除、确认持久化、只读详情和刷新恢复。

依据：产品需求 I01、I03–I07 及语言选择前置；[核心契约第 6.6 节](../CORE_ENGINE.md#66-逐行确认与持久化契约)；[页面规格 P01–P03](../WEB_UX.md)；[工程方案](../DEVELOPMENT.md)。本阶段验证 C01、C03、C04、C08、C09、C11 的基础子集及 A04、A23 的对应行为，不宣称这些交付项整体通过。

本阶段每次只处理一篇课文。自动分句、多篇自动划分、JSON 导入导出、删除课文、三种训练、真实 PDF/OCR/ASR 及模型资源管理留给后续；本阶段界面只呈现可用操作，文案遵循[通用交互规则](../WEB_UX.md#72-通用交互规则)。

实现授权已取得，依赖兼容性已验证，环境和命令见[工程指南](../DEVELOPMENT.md#开发命令与验证)。首个接入语言为英语 en，不自动预选；这里只交付导入能力，不将未具备提示和比较能力的模块标为完整训练支持。

本阶段采用显式“保存草稿”，成功后刷新可恢复；未保存修改在应用内离开时提示保存或放弃，浏览器刷新/关闭使用可用的离开提示，不承诺拦住系统终止。确认期间禁用重复操作，失败留在编辑窗口。

本阶段已确认的输入上限：正文最多 20,000 个 Unicode 码点、最多 500 个非空行；先校验长度再分析，超限明确拒绝并保留输入，不截断。此为导入限制，后续比较单位上限单独配置。

## 用户验收

在仓库根目录执行 `npm ci`、`npm run dev`，打开 http://127.0.0.1:5173。生产产物验收执行 `npm run build`、`npm run preview`，打开 http://127.0.0.1:4173。用户在同一浏览器、同一站点来源内测试；两个端口的数据互不共享。实际测试环境为 Windows x64、Node.js 24.21.0、npm 12.2.0、Playwright Chromium 156.0.8078.4，窄屏为 375 × 812 CSS px。本次构建对应 包含本交付记录的详情页及确认窗口简化提交，文档基线为 `6159e74`。正式跨浏览器支持在发布阶段确定。

准备含多行句子、长句以及同一行内多个句号的英语材料；另备空白、仅标点和包含脚本文字的文本。

| 检查项 | 操作 | 可观察结果与依据 |
| --- | --- | --- |
| 语言前置 | 新建导入，未选语言时尝试输入 | 导入未启用，选择后可继续；A23 |
| 按行输入 | 粘贴含换行及同一行多个句号的文本 | 编辑窗口提示“每行一句”，保留原换行，不按句号拆行；I03–I04 |
| 人工边界 | 改字、回车拆行、删除换行合行，再确认 | 编辑器长句横向滚动，实际换行划分下一句；详情按最终行边界展示；I03–I04 |
| 无效内容 | 输入空白、仅标点正文或仅标点的非空行 | 阻止确认并指出问题位置；I05、A04 |
| 草稿恢复 | 修改后保存草稿，刷新并重新打开 | 标题、语言和编辑内容保持；核心第 6.6 节 |
| 删除草稿 | 分别从课文库和已保存草稿编辑页点击“删除草稿”，先取消，再确认删除并刷新 | 取消时内容保持；确认后草稿消失，编辑页返回课文库；已有确认课文保持；I07 |
| 未保存离开 | 修改后返回课文库 | 提示保存或放弃，取消离开后内容保持；通用交互规则 |
| 确认持久化 | 确认保存，返回课文库，刷新并打开详情 | 课文存在、内容正确，已确认草稿不重复展示；I05 |
| 只读 | 尝试更改已保存的标题、正文或语言 | 无编辑入口；I06、A17、A28 的课文只读部分 |
| 重复操作 | 连续点击确认，刷新列表 | 只有一篇对应课文；核心第 6.6 节 |
| 错误状态 | 打开不存在的详情 ID；按交付说明模拟存储失败 | 前者明确不存在，后者显示失败并允许重试；保存失败不丢输入 |
| 限制与安全 | 输入超限文本及脚本文字 | 超限不截断、不保存；脚本文字普通显示，不执行 |
| 窄屏与输入法 | 窄屏编辑长句，输入法合成，再保存 | 长句可在编辑器内横向滚动，页面无横向溢出；操作可见，合成过程不误提交；通用交互规则 |

存储故障验收使用 `npm run dev` 的一次性模拟入口，不需要修改程序：

1. 打开 http://127.0.0.1:5173/library?storageFailure=once，显示读取失败；点击“重试”，应恢复课文库，而不是显示课文不存在。
2. 打开 http://127.0.0.1:5173/import?storageFailure=once，选择英语并填写正文，点击“保存草稿”，显示保存失败且输入保持；再次点击保存，应成功并可刷新恢复。
3. 重新打开上述导入故障地址，填写新正文，不先保存草稿，直接“确认并保存”→“确认保存”，应失败并回到保留输入的编辑器；重新确认，应只生成一篇课文。

故障参数在第一次存储操作时移除，后续重试正常；该入口仅存在于开发模式，生产预览不模拟失败。真实事务中止回滚由自动集成测试验证。用户行边界解析、码点映射、持久化失败及重复确认由自动测试先验证，用户检查可见行为。
