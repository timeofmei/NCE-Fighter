# 阶段 01：文本导入与只读课文

## 状态与范围

状态：待审核。应用尚未实现，本文是实施和验收计划。

目标：交付可以运行的文本导入闭环，覆盖课文库、语言选择、粘贴文本、逐行校对、草稿保存、确认持久化、只读详情和刷新恢复。

依据：产品需求 I01、I03–I06 及语言选择前置；[核心契约第 6.6 节](../CORE_ENGINE.md#66-逐行确认与持久化契约)；[页面规格 P01–P03](../WEB_UX.md)；[工程方案](../DEVELOPMENT.md)。本阶段验证 C01、C03、C04、C08、C09、C11 的基础子集及 A03、A04、A23 的对应行为，不宣称这些交付项整体通过。

本阶段每次只处理一篇课文。多篇自动划分、JSON 导入导出、删除课文、三种训练、真实 PDF/OCR/ASR 及模型资源管理留给后续；这些功能若展示入口，必须注明尚未实现。

前置条件：用户审核当前阶段及变更的规范；初始化时确认依赖兼容性。首个接入语言建议为英语 en，待用户审核，不自动预选；这里只交付导入能力，不将未具备提示和比较能力的模块标为完整训练支持。

初期提供显式“保存草稿”，成功后刷新可恢复；未保存修改在应用内离开时提示保存或放弃，浏览器刷新/关闭使用可用的离开提示，不承诺拦住系统终止。确认期间禁用重复操作，失败留在编辑窗口。自动保存若后续采用，另行更新交互规范。

阶段提出的输入保护建议：正文最多 20,000 个 Unicode 码点、最多 500 个非空行；先校验长度再分析，超限明确拒绝并保留输入，不截断。此为导入限制，后续比较单位上限单独配置，须审核后采用。

## 用户验收

交付时由开发代理填写启动命令、地址、实际测试环境和构建对应提交。目前尚无运行地址。用户在同一浏览器、同一站点来源内测试；移动端至少验证窄屏操作，正式跨浏览器支持在发布阶段确定。

准备包含缩写、小数、长句和多句文本的英语材料；另备空白、仅标点和包含脚本文字的文本。

| 检查项 | 操作 | 可观察结果与依据 |
| --- | --- | --- |
| 语言前置 | 新建导入，未选语言时尝试输入 | 导入未启用，选择后可继续；A23 |
| 首次分句 | 输入含 Mr. Smith、3.14 的文本进入校对 | 预填可编辑内容，缩写及小数不机械拆分；A03 |
| 人工边界 | 改字、回车拆行、删除换行合行，再确认 | 详情按最终行边界展示，视觉折行不增句；I03–I04 |
| 无效内容 | 输入空白、仅标点正文或仅标点的非空行 | 阻止确认并指出问题位置；I05、A04 |
| 草稿恢复 | 修改后保存草稿，刷新并重新打开 | 标题、语言和编辑内容保持；核心第 6.6 节 |
| 未保存离开 | 修改后返回课文库 | 提示保存或放弃，取消离开后内容保持；通用交互规则 |
| 确认持久化 | 确认保存，返回课文库，刷新并打开详情 | 课文存在、内容正确，已确认草稿不重复展示；I05 |
| 只读 | 尝试更改已保存的标题、正文或语言 | 无编辑入口；I06、A17、A28 的课文只读部分 |
| 重复操作 | 连续点击确认，刷新列表 | 只有一篇对应课文；核心第 6.6 节 |
| 错误状态 | 打开不存在的详情 ID；按交付说明模拟存储失败 | 前者明确不存在，后者显示失败并允许重试；保存失败不丢输入 |
| 限制与安全 | 输入超限文本及脚本文字 | 超限不截断、不保存；脚本文字普通显示，不执行 |
| 窄屏与输入法 | 窄屏编辑长句，输入法合成，再保存 | 操作可见、无横向溢出，合成过程不误提交；通用交互规则 |

存储故障的复现方式由开发代理随实现补充到本文件，不能要求用户自行修改程序。首次分句、人工边界、码点映射、持久化失败及重复确认由自动测试先验证，用户检查可见行为。
